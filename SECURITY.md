# Security Policy

## Supported Scope

NeuroSwift is an experimental research repository. Security reports are welcome for:

- unsafe dependency usage
- code execution risks in scripts
- malicious file handling
- data leakage risks in future dataset or checkpoint workflows

## Reporting A Vulnerability

Please do not open public issues for suspected vulnerabilities.

Instead, share:

- a clear description of the issue
- affected files or scripts
- reproduction steps
- severity and likely impact
- any suggested mitigation

## Response Goals

Best effort targets:

- acknowledge the report within 7 days
- assess severity and impact
- provide a fix or mitigation path when practical

## Disclosure

Please allow time for triage and patching before public disclosure.

## Notes

This repository is a small research project created by Vikash Kumar, so response times may vary.
