# Example Data

This folder contains example training data for NeuroSwift.

- `neuroswift_corpus.txt`: a synthetic newline-delimited corpus with more than 5,000 training lines for small-model experiments on CPU.
- `neuroswift_qa.jsonl`: an instruction-style dataset with more than 5,000 prompt/response pairs for question answering and assistant-style training.

The dataset is intended for architecture validation and demo-quality language modeling, not benchmark-grade evaluation.
